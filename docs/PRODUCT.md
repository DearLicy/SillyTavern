# SillyTavern APP 产品规格

## 定位

**SillyTavern APP** 是本地优先、BYOK 为核心的移动端 LLM 前端，面向角色扮演、互动叙事与创作。它把 SillyTavern 最常用的角色卡、世界书、Prompt Manager、正则、Chat Completion Preset、用户人设与长期记忆带入 Android、iOS 和 Web。

产品不是通用 AI 助手，不是乙游/梦女产品，也不是 SillyTavern 官方云服务的客户端。没有账号、云同步、真实用户社交、动态社区、关系数值、导演模式或会员聊天次数。

## 信息架构

### 根页面

1. **会话首页**：最近会话、置顶、免打扰、未读、搜索与群聊。
2. **角色库**：角色卡列表、搜索、标签筛选与创建入口。

会话首页和角色库都是全屏根页面，两者之间通过显式入口切换；应用没有常驻底部导航。聊天、角色资料、世界书、预设、记忆、设置、备份等全部为全屏二级页面。

### 侧滑菜单

- 本地用户资料；
- 可选用户人设；
- 角色库与角色卡管理；
- 世界书；
- 提示词与预设；
- 长期记忆；
- 隐私与安全；
- 数据与备份；
- 模型与供应商设置；
- 主题与关于。

## 角色卡

角色卡是产品中心。一个角色可以拥有多个会话、分支和用户人设组合；会话不是角色本身。

### 支持字段

- 名称、头像、标签与作者；
- description；
- personality；
- scenario；
- first message；
- alternate greetings；
- message examples；
- character system prompt；
- post-history instructions；
- creator notes；
- 内嵌 character_book；
- 旧版扩展字段中的 handle、age、voice profile 与偏好。

### 导入导出

- Character Card V2 JSON；
- PNG `ccv3` / `chara` 元数据；
- PNG 回写时优先嵌入角色头像；
- 未知字段和脚本不执行；
- 导入不会强制要求先创建用户人设。

## 用户人设

用户人设是可选的。每套人设包含姓名、年龄、称呼、外观、性格、背景与偏好。未选择人设时，角色卡中的 `{{user}}` 回退为本地用户资料。

不同用户人设可以绑定到不同会话，避免在多个故事中长期混淆身份。

## 世界书与作者注记

- 主关键词与次关键词；
- 常驻词条；
- 大小写与触发概率；
- 扫描条数和单书条目上限；
- 递归层数与插入深度；
- 条目排序与启用开关；
- 每本世界书的作者注记与注记深度；
- SillyTavern Lorebook JSON 导入、导出与内嵌角色书转换。

世界资料只是可纠正的设定，不能覆盖平台安全约束或用户本轮明确纠正。

## Prompt Manager 与生成参数

- 全局系统提示词；
- post-history instructions；
- 命名提示词块与独立启用开关；
- System / User / Assistant 消息角色；
- 角色卡前、角色卡后、历史前与消息深度注入；
- Prompt Manager 条目排序，以及 Chat Completion Preset 中的命名提示词保留；
- 输入与输出正则规则；
- 捕获组替换、大小写、多行与点号匹配；
- 工程内提示词预设导出；
- SillyTavern Chat Completion Preset 导入；
- 温度、Top P、频率惩罚、存在惩罚、最大输出 Token 和停止序列；
- 聊天级宏变量与有界展开。

不执行任意 JavaScript、Shell、远程脚本或角色卡/预设内的可执行扩展。

## 聊天

### 生成与呈现

- OpenAI Compatible、Anthropic 和 DeepSeek 官方；
- 模型从真实 `/models` 目录拉取，不手填模型 ID，不使用模拟目录；
- SSE、普通 JSON 和不带正文流量的推理模型兼容；
- 空流最多追加一次同供应商非流式请求；
- 中英文括号动作显示为气泡外旁白；
- 空内容、协议残留和内部推理不进入角色气泡；
- 最近回复相似度检测与静默重写，避免连续复读。

### 聊天管理

- 搜索、查看、复制、编辑与删除消息；
- 单条删除、多选删除和搜索结果批量删除；
- 清空聊天但保留角色卡与手动记忆；
- 重新开始聊天；
- 从任意消息创建独立分支；
- 多角色群聊；
- 附件引用清理与派生摘要重建。

## 长期记忆

记忆类型：

- 用户事实；
- 互动事实；
- 共同经历；
- 承诺；
- 情绪；
- 剧情状态；
- 用户明确边界。

检索优先级：边界、固定项、与当前输入相关、近期。记忆可查看来源、编辑、固定和删除。

长对话会在正常回复完成后，通过同一 BYOK 供应商发起独立的非流式整理请求。结果只写入本地摘要与事实记录，不显示在聊天气泡中。应用关闭后不会静默调用模型。

## 图片与多模态

- 相册与相机图片；
- 发送前预览和说明文字；
- OpenAI/Anthropic 真实图片内容块；
- 最近图片随上下文重新发送；
- 重试和分支保留附件引用；
- 图片原件不写入主数据库；
- DeepSeek 官方 OCR 与联网搜索；
- DeepSeek 官方 ASR 与 TTS。

第三方聊天 Key 不会自动用于 DeepSeek 官方工具；工具 Key 在原生端进入系统安全存储，普通备份不包含密钥。

## 供应商与本地数据

- DeepSeek 官方为首次安装默认供应商；
- 支持 OpenAI Chat Completions 兼容与 Anthropic Messages 兼容地址；
- 模型目录、错误、CORS 和空流问题必须在真实请求中暴露；
- 不跨供应商复用 Key；
- 没有自建账号、云同步、遥测或内容中转；
- Web 使用浏览器本地存储与 IndexedDB；
- 原生端使用 SQLite、系统安全存储和应用私有附件目录。

## 内容边界

| 级别 | 范围 |
| --- | --- |
| SFW | 日常、冒险、友情、剧情 |
| Mature | 成熟主题、情感张力与成人向表达 |
| NSFW | 明确成年、自愿的虚构角色成人文字 RP |

平台安全约束优先于角色卡、世界书、预设与用户提示词。用户要求停止、跳过或结束场景时必须立即尊重。

| **V2.4** | 原生 TTS/ASR 体验、图片角色卡导入、移动端多模态上下文优化 |

## 明确不做

- 乙游/梦女关系数值、导演模式、动态社区与恋爱日程；
- 真实用户社交、关注、私信、举报和云端社区；
- 会员聊天次数制；
- 未经授权的官方角色复刻；
- SillyTavern 账号、云同步或聊天内容云托管；
- 未经审查地执行第三方 SillyTavern JavaScript 插件。
