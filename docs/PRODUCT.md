# SillyTavern V2 产品规格

## 定位

**SillyTavern APP** 是本地优先、BYOK 为核心的 LLM 前端产品，面向角色扮演、AI 陪伴与创作。用户通过角色、世界观、记忆与导演模式，体验可持续的 AI 互动。用户通过梦设、AI 角色、关系状态、长期记忆、导演模式和梦境空间，经营可持续发展的虚构恋爱关系。

产品不是通用 AI 助手，也不是单一模型客户端。它支持多模型、多角色，并提供角色卡、世界观、记忆、导演模式等扩展功能，兼容 OpenAI/Anthropic/DeepSeek 等主流服务商。

## 核心结构

### 三个根页面

1. **消息**：最近会话、置顶、未读、免打扰、搜索和关系阶段。
2. **联系人**：角色、分组、关系和群聊入口。
3. **动态**：梦境空间，用户与 AI 角色发布文字动态、点赞和评论。

只有三个根页面显示底部导航。聊天与所有管理页面使用全屏二级路由。

### 侧滑资料

根页面头像打开侧滑抽屉：

- 本地用户资料；
- 切换梦设；
- 收藏与记忆；
- 隐私与安全；
- 数据与备份；
- 设置；
- 夜间模式；
- 关于。

## 关系模型

一条关系由以下内容唯一确定：

- 一个本机用户；
- 一套梦设 `UserPersona`；
- 一位 AI 角色 `Character`；
- 一段 `Relationship`；
- 一个参与者感知的 `ChatThread`；
- 一组关系级边界与内容上限。

同一角色可以拥有多条平行关系，但梦设、记忆、称呼、场景和边界彼此独立。

关系不是固定标签。每次成功互动会依据用户是否分享近况、表达亲近、形成共同安排、冷淡或冲突来改变好感、信任、心动与张力，并推动阶段变化。关系页显示上轮变化及原因；重新生成同一条回复只改变表达，不重复刷数值。

角色会避免连续复用相同开场、句式、比喻、动作和收尾。命中高度相似时，客户端会静默重写一次再落入聊天，不把内部重写过程展示给用户。

## 长期记忆

记忆类别：

- 用户信息；
- 关系信息；
- 共同经历；
- 重要承诺；
- 情绪记忆；
- 剧情状态；
- 用户边界。

记忆必须可查看来源、编辑、固定和删除。固定项、边界项和当前输入相关的记忆优先进入提示词。

长对话会在正常回复完成后由同一 BYOK 供应商单独、静默地归纳旧对话，结果保存在本地会话备忘，并随之后的主对话提交。整理失败不影响聊天，也不覆盖上一版备忘；原始消息仍保留。整理涉及的历史片段会额外发送给当前模型供应商。该请求只在应用运行且用户仍使用聊天时触发，不在应用关闭后静默调用；每次最多整理 16 条旧消息、保留最近 8 条原文。自动事实保留消息来源，不会自动新增或覆盖用户边界。

## 图片消息

支持从相册选择或调用系统相机拍摄图片，发送前可预览并添加说明文字。原生端附件保存在应用私有目录，Web 保存在 IndexedDB，消息记录只保存附件引用。发送时使用真实图片内容块，重试和重新生成沿用原件；是否具备像素级视觉理解取决于所配置的模型能力。

失败请求可以直接重试上一条；最新角色回复可以重新生成。重试和重新生成不会重复用户消息，也不会把内部错误或模型推理显示在聊天气泡中。

## 导演与场景

导演模式只调整当前剧情，不修改角色卡：

- 节奏：慢热 / 自然 / 强推进；
- 旁白比例；
- 角色主动性；
- 场景亲密程度；
- 本轮自然语言指令；
- 重置场景但保留长期关系记忆。

## 内容级别

| 级别 | 体验 |
| --- | --- |
| SFW | 日常、恋爱、友情、剧情 |
| Mature | 成熟恋爱、暧昧、性感表达 |
| NSFW | 明确成年、自愿的虚构角色之间的成人文字 RP |

全局上限限制所有关系；每段关系可以更低，但永远不能更高。

## 梦境空间

V2.0 只支持文字动态：

- 用户发布文字；
- AI 角色发帖；
- 点赞；
- 评论与 AI 回复。

图片、视频、AI 图像与剧情相册安排在 V2.3。

## 纯本地边界

- 没有真实用户好友；
- 没有关注、私信、举报、云端社区；
- 没有 SillyTavern 账号；
- 没有云同步；
- 模型请求直接从本机发往用户配置的供应商；
- 所有角色、动态、关系和记忆均为本地数据。

## 当前交互修订（2026-11-19）

- 首次启动为空白产品；不预置梦设、角色、消息、记忆或动态。
- 默认连接 DeepSeek 官方，模型从认证接口拉取并选择，禁止用模拟目录掩盖失败。
- 未配置供应商时不回复模拟内容，保留输入草稿。
- AI 的中英文括号动作拆为气泡外旁白，兼容 V1 的单星号与引用旁白。
- 使用 Forui 表单、按钮与弹层；取消列表与切栏位移动画，缩小圆角并移除重阴影。
- 文字动态只保存真实输入，不自动插入模拟角色评论或点赞。角色模型驱动的动态互动仍待开发。


## 数据管理交付（2026-11-21）

- 聊天菜单、消息长按和角色资料均能进入「聊天与数据」。
- 记录支持按正文/发送者搜索、全文查看、复制、编辑、单条删除、多选、全选搜索结果和批量删除。
- 明确区分清空消息、重新开始当前梦设关系、删除整个角色，逐项解释影响并二次确认。
- 重新开始保留用户硬边界和人设，删除共同记忆并重置关系/场景；不自动发问候或植入示例。
- 动态正文和评论支持真实编辑/删除，不再保留无操作的更多图标。
- 梦设删除对绑定关系进行约束；角色改名同步对话标题。
- 当时尚未交付的头像、识图、语音已在下节独立列出；V2.1 的关系日历、纪念日与主动消息仍待交付。


## 多模态交付（V2.0.5）

资料头像（含梦设/角色）、真实图片识图、DeepSeek Search 来源、OCR 草稿、语音输入草稿、消息朗读已接入；完整媒体 JSON 备份恢复覆盖这些头像与图片。入口和状态见 `PROVIDER-CAPABILITIES.md`，验收不能仅检查按钮存在，必须确认请求携带真实内容与持久化恢复。

本次 UI 复用现有 QQ 式全屏聊天结构：麦克风、文本、常驻加号、发送各有明确入口，功能面板为 Forui 底部 sheet，取消不写入内容，不添加装饰性弹跳。关系日历、纪念日、主动消息、群聊、语音原件、实时通话仍按原路线独立交付。


## SillyTavern 兼容层

### 角色卡

- 支持 Character Card V2 JSON 导入与导出。
- 支持 PNG `ccv3` / `chara` tEXt 与未压缩 iTXt 元数据导入。
- 导入 `character_book` 时转换为本地世界书；未知字段与脚本不会执行。
- `{{char}}` / `{{user}}` 宏在提示词组裝时展开。

### 世界书与作者注记

- 主关键词、次要关键词 AND 条件、大小写、触发概率、扫描消息数、单书条目上限、递归层数、常驻词条、排序和启用开关均参与提示词注入。
- 词条支持插入深度：0 紧贴本轮输入，数字越大越靠近历史前部；每个世界书独立扫描自己的近期消息窗口。
- 每本世界书支持作者注记和注入深度，用于长期语气、视角和叙事风格约束。
- 世界书资料属于可纠正的世界设定，不得覆盖平台安全规则与用户边界。


### 提示词与正则规则

- Prompt Manager 提供全局系统提示词和后置指令；它们只调整风格和格式，不能覆盖安全规则、用户边界或本轮纠正。
- 正则规则支持用户输入与 AI 输出两个作用位置，可配置执行顺序、大小写、多行和点号换行匹配。
- 替换支持 `$1`、`${1}`、`$&` 与 `$$`。规则只在本机执行正则替换，不运行 JavaScript、Shell、网络请求或角色卡内脚本。
- 输入、表达式和输出均有长度上限；无效表达式会在保存前被拒绝，聊天时也不会执行。
