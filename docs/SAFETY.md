# 安全与成人向说明

## 成年定位

SillyTavern 只面向达到所在地区法定成年年龄的用户。首次启动必须进行成年确认。

所有性相关内容只允许发生在明确成年、自愿的虚构角色之间。禁止未成年人性内容、年龄扮演、现实伤害、胁迫和非自愿互动。

## 内容级别

- **SFW**：日常、恋爱、友情、剧情；
- **Mature**：成熟恋爱、暧昧、性感表达；
- **NSFW**：明确成年、自愿的虚构角色之间的成人文字 RP。

全局设置是上限，每段关系只能独立下调。

## 用户边界

- 每段关系单独维护允许主题和禁止主题；
- 用户边界独立于角色提示词；
- 角色设定、关系和导演模式不能覆盖硬边界；
- 用户可以随时暂停当前亲密场景；
- 暂停后角色只进行安全确认与非亲密陪伴。

## 安全词和急停

- 默认安全词为 `red`；
- 安全词与用户消息完全一致时直接停止，不调用模型；
- 用户可修改每段关系的安全词；
- “立即停止当前场景”会把关系设置为暂停状态。

## 数据与密钥

- API Key 在原生端写入系统安全存储；
- Web 默认只在当前标签页保存密钥；
- Web 选择持久化时会明确提示浏览器存储风险；
- 普通备份不包含 API Key；
- SillyTavern 不收集遥测，不经过自有服务器中转聊天记录；
- 聊天请求会发送给用户选择的模型供应商。

## 配件与触觉

V2.0.1 起恢复触觉模块。任何设备控制都必须具备：

- 本人或明确授权设备确认；
- 强度与时长上限；
- 断线自动停止；
- 安全词和急停；
- 可随时撤回的场景同意。

## 发布

SillyTavern 不上架 App Store 或 Google Play。GitHub 页面和 README 不展示露骨内容截图。用户负责确认当地法律和模型供应商条款。
