# 安全与成人内容说明

## 成年定位

SillyTavern APP 只面向达到所在地区法定成年年龄的用户。首次启动必须进行成年确认。

性相关内容只允许发生在明确成年、自愿的虚构角色之间。禁止未成年人性内容、年龄扮演、现实伤害、胁迫和非自愿互动。

## 内容级别

- **SFW**：日常、冒险、友情和剧情；
- **Mature**：成熟主题、情感张力与成人向表达；
- **NSFW**：明确成年、自愿的虚构角色成人文字角色扮演。

内容级别是应用级全局设置，不是角色之间的关系分数。角色卡、世界书、Prompt Manager 或 Chat Completion Preset 不能突破平台安全约束。

## 停止与撤回

- 用户明确要求停止、跳过、暂停或结束场景时，角色必须立即尊重；
- 停止是当前对话中的明确用户意图，不需要预设安全词；
- 回忆或角色设定不能覆盖用户本轮纠正；
- 平台安全约束优先于角色卡 `system_prompt`、世界书、作者注记和预设。

## 数据与密钥

- 原生端 API Key 写入系统安全存储；
- Web 默认只在当前标签页保存密钥；
- Web 选择持久化时明确提示浏览器存储风险；
- 普通备份不包含 API Key；
- 不收集遥测，不通过自有服务器中转聊天记录；
- 聊天请求会发送到用户选择的模型供应商；
- 第三方供应商 Key 不会自动发送到 DeepSeek 官方工具域名。

## 本地数据

角色、用户人设、聊天、记忆、世界书、附件与备份默认保存在本机。清理站点数据或卸载应用可能删除 Web 本地数据，用户应自行保存备份。

## 发布边界

SillyTavern 不上架 App Store 或 Google Play。GitHub 页面和 README 不展示露骨内容。用户负责确认当地法律、模型供应商条款和内容授权。
